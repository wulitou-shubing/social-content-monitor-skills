# Support

Use GitHub Issues for reproducible bugs, installation failures, documentation problems, and feature requests. Use GitHub Discussions for usage questions, platform ideas, and examples after Discussions are enabled.

Before posting

- remove cookies, tokens, private Lark links, personal account lists, local paths, and copyrighted media
- include the Agent client, operating system, Python version, `ffmpeg` version, affected Skill, and exact error
- explain whether the source was a local file or an authorized public URL
- state whether the failure happened during discovery, metadata writing, download, transcription, or transcript update

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and do not publish sensitive details in an Issue.
