# 脱敏演示

这是一份虚构数据演示，用来说明两个 Skill 配合以后会留下什么结果。它不包含真实创作者、飞书链接、账号 ID、Cookie 或下载文件。

## 用户交给 Agent 的任务

```text
监控我配置好的公开创作者账号。只处理基线以后发布的新作品，把作品信息写入飞书，并为有语音的视频生成带时间戳的口播文案。
```

## 带时间戳的听写稿

```text
[00:00.00] 今天用三步把一条行业资讯整理清楚。
[00:03.20] 第一步确认消息来自哪里，第二步核对时间和原文。
[00:07.80] 最后再把结论和仍然不确定的地方分开记录。
```

## 写入顺序

1. 监控 Skill 核对作品归属和稳定内容 ID。
2. 它使用唯一键查询飞书，确认这条作品没有入库。
3. 它先创建作品信息记录，并把转写状态设为 `pending`。
4. 转写 Skill 下载有权限访问的视频并生成时间戳文字稿。
5. 监控 Skill 更新原来的飞书记录，把文案和状态写回去。

如果下载或识别失败，作品信息仍然保留，状态改为 `failed`。下一次重试更新同一条记录，不会另建重复行。
