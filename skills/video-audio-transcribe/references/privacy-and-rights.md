# Privacy, authentication, and rights

- Download only media the user is authorized to access and process.
- Follow the target site's terms, access controls, and applicable copyright/privacy rules.
- Browser cookies are authentication material. Request approval before using them and pass them directly to `yt-dlp`; never inspect, print, export, or commit them.
- Do not bypass CAPTCHA, login verification, rate limits, paywalls, private-account controls, DRM, or other technical restrictions.
- Stop on verification or rate-limit responses. Ask the user to restore a normal signed-in session rather than automating around the control.
- Store outputs only in the user-approved location. Do not upload media or transcripts to another service unless the user requested it.
- Transcripts can contain personal or confidential speech. Treat them with the same sensitivity as the original media.
